# Getting Started

## Installation

Add gpui-query to your `Cargo.toml`:

```toml
[dependencies]
gpui-query = "2.0"
```

Import the prelude in your Rust files:

```rust
use gpui_query::prelude::*;
```

## Setup

Create a `QueryClient` and register it in your GPUI application. The client is the central hub that manages all query state, caching, and coordination.

```rust
use gpui::prelude::*;
use gpui_query::prelude::*;

fn main() {
    let app = Application::new().with_assets(assets);
    app.run(move |cx| {
        // Create the query client
        let client = QueryClient::new();

        // Register it as a global in your app
        cx.set_global(client);

        // Open your main window
        cx.open_window(default_window_options(), |window, cx| {
            cx.new_view(|cx| RootView::new(cx))
        });
    });
}
```

## Your First Query

Use `use_query` to fetch data asynchronously. The hook returns a `QueryResource` that tracks loading state, data, and errors.

```rust
use gpui_query::use_query;

fn user_profile_view(cx: &mut ViewContext<App>) {
    let query = use_query(
        cx,
        QueryKey::from("user-profile"),
        |cx| async move {
            fetch_user_profile().await
        },
        QueryOptions::default(),
    );

    // Access the data reactively
    if let Some(data) = query.data() {
        // Render the user profile
        cx.render(|_| div().child(format!("Hello, {}!", data.name)));
    } else if query.is_loading() {
        cx.render(|_| div().child("Loading..."));
    }
}
```

## Understanding QueryResource

`QueryResource<T, E>` is the core type returned by query hooks. It provides:

| Field           | Type              | Description                      |
| --------------- | ----------------- | -------------------------------- |
| `data`          | `Option<T>`       | The latest resolved data         |
| `status`        | `QueryStatus`     | Current lifecycle state          |
| `is_fetching`   | `bool`            | Whether a fetch is in progress   |
| `is_refetching` | `bool`            | Whether a refetch is in progress |
| `error`         | `Option<E>`       | The latest error, if any         |
| `updated_at`    | `Option<Instant>` | When data was last updated       |

## Query Status

Queries go through a defined lifecycle:

```rust
match query.status() {
    QueryStatus::Idle => { /* Not yet started */ }
    QueryStatus::Pending => { /* Fetch in progress */ }
    QueryStatus::Success => { /* Data is available */ }
    QueryStatus::Error => { /* Fetch failed */ }
}
```
