# API Reference

Complete listing of all public types, functions, and traits across gpui-query's three layers.

## Core Layer (`gpui_query::core`)

### `QueryKey`

```rust
pub struct QueryKey(/* private */);
impl QueryKey {
    pub fn new(key: &str) -> Self;
}
impl Clone for QueryKey
impl Hash for QueryKey
impl Eq for QueryKey
impl Into<QueryKeyFilter> for QueryKey
```

### `QueryStatus`

```rust
pub enum QueryStatus {
    Idle,
    Pending,
    Success,
    Error,
}
```

### `QueryResource<T, E>`

```rust
pub struct QueryResource<T, E> {
    pub data: Option<T>,
    pub status: QueryStatus,
    pub is_fetching: bool,
    pub is_refetching: bool,

```

## Client Layer (`gpui_query::client`)

### `QueryClient`

```rust
impl QueryClient {
    pub fn new() -> Self;
    pub fn resource<T, E>(&self, key: &QueryKey) -> Option<QueryResource<T, E>>;
    pub fn query<T, E>(&self, key: &QueryKey) -> Option<&QueryResource<T, E>>;
    pub fn invalidate_queries(&self, filter: QueryKeyFilter);
    pub fn reset_queries(&self, filter: QueryKeyFilter);
    pub fn remove_queries(&self, filter: QueryKeyFilter);
    pub fn cancel_queries(&self, filter: QueryKeyFilter);
    pub fn gc(&self);
    pub fn get_query_data<T>(&self, key: &QueryKey) -> Option<T>;
    pub fn set_query_data<T>(&self, key: &QueryKey, data: T);
    pub fn prepare_fetch<T, E>(&self, key: &QueryKey, fetcher: impl Future<Output = Result<T, E>>);
    pub fn prefetch_query<T, E>(&self, key: &QueryKey, fetcher: impl Future<Output = Result<T, E>>);
    pub fn dehydrate(&self) -> DehydratedState;
    pub fn hydrate(&self, state: DehydratedState);
    pub fn persist(&self, persister: &dyn QueryPersister) -> Result<()>;
    pub fn restore(&self, persister: &dyn QueryPersister) -> Result<()>;
    pub fn diagnostics(&self) -> ClientDiagnostics;
}
```
